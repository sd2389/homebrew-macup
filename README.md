# Homebrew tap for MacUp

```bash
brew install sd2389/macup/macup
```

[MacUp](https://github.com/sd2389/macup) shows what is outdated across
Homebrew, npm, mise, and macOS, and never changes anything in this version.

The formula builds MacUp from source on your Mac. It needs macOS 14 or later
and the Xcode Command Line Tools (`xcode-select --install`).

Remove it with `brew uninstall macup` and `brew untap sd2389/macup`.
